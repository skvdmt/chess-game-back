# chess-game-back

### Translations
[En](./README.md)

### Описание
Приложение для игры в шахматы.

Приложение работает на порту указаном в [конфигурационном файле](./config/prod.yaml).

Клиенты должны использовать WebSocket для подключения к серверу.

### Скачать

```sh
git clone https://github.com/skvdmt/chess-game-back
```
